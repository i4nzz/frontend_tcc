# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

Note: this project was intentionally downgraded from SDK 57 to SDK 54 on
2026-08-16 because the Expo Go app installed on the author's test device was
stuck on SDK 54 (Play Store update wasn't propagating). On 2026-09-12 the
device's Expo Go updated to SDK 57, so the project was upgraded back
(`npm install expo@latest && npx expo install --fix`) to follow the "always
use the latest stable Expo SDK" rule from the frontend spec.
